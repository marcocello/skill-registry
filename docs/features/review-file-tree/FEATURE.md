# Review bundle file tree

Admins inspect pending proposal bundles using the same collapsible folder tree as the skill Files tab.

- AC1-tree: Nested files remain selectable through expanded/collapsed folders. Selecting a text file shows its editable content; binary assets are identified and preserved.
- AC2-save: Saving an edited file persists the complete bundle. Unsaved changes are visible and approval requires saving them first.

Reuse the current bundle tree and permission model. No file creation/deletion UI is added.
